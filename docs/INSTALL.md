# Telepítés

A támogatott automatikus célrendszer Debian vagy Ubuntu, systemd-vel és interneteléréssel. A telepítő root jogosultságot csak csomagtelepítéshez és hostos Nginx/TLS beállításhoz kér.

A domain DNS rekordját előre irányítsd a szerver publikus IP-címére. Dockeres reverse proxy esetén add meg annak külső Docker-hálózatát.
