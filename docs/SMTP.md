# SMTP

## Gmail
- Host: `smtp.gmail.com`
- Port: `587`
- Security: `starttls`
- Auth: `Login`
- Jelszó: Google alkalmazásjelszó, nem a normál fiókjelszó

## Microsoft 365
- Host: `smtp.office365.com`
- Port: `587`
- Security: `starttls`
- Auth: `Login`

A tenant és a postafiók szabályaitól függően az SMTP AUTH külön engedélyezést igényelhet.
